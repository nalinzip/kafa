# K.A.F.A. - Korea-ASEAN Flood Assistance System

Responsive website prototype for a government flood-management and emergency
decision-support platform focused on Aceh Utara, Aceh, Sumatra, Indonesia.

The prototype demonstrates four connected operational modules:

- Overview
- Real-Time CCTV
- Flood Risk Management
- Rescue Priority Management

All maps, monitoring points, simulated CCTV, flood-risk zones, and rescue
incidents use the same Aceh Utara operational geography centered on Lhoksukon
and the Krueng Keureuto basin.

All operational values are mock/simulated data for demonstration purposes.

## Development

```bash
npm install
npm run dev
npm run build
```
